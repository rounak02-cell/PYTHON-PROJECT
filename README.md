PYTHON-PROJECT 🐍
A collection of beginner-friendly Python mini-projects: a Calculator and a Who Wants to Be a Millionaire quiz game.
Repo: https://github.com/rounak02-cell/PYTHON-PROJECT
1. Calculator
A simple command-line calculator that performs addition, subtraction, multiplication, and division.
Run:
python CALCULATOR/main.py
3. Who Wants to Be a Millionaire (Quiz Game)
A console-based quiz game with multiple-choice questions and increasing prize money for correct answers.
Run:
python MILLIONAIRE/main.py
Tech Stack
Python 3 (standard library only)
